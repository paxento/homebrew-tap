# paxento/homebrew-tap

```bash
brew install --cask paxento/tap/claude-translates
```

A translation window for macOS that runs on your Claude subscription instead of
a paid API key. Select text, press a hotkey or tap `⌘C` twice, and get the
original and the translation side by side.

Signed and notarised by Apple, so it opens on a double click.
